# Описание тестов Flutter приложения

## Общая информация

Тесты находятся в двух файлах:
- `test/widget_test.dart` - виджет-тесты UI
- `test/api/backend_flow_test.dart` - интеграционные тесты API

Все тесты выполняются против реального бэкенда: `https://excursion.panfilius.ru`

---

## 1. Виджет-тест (widget_test.dart)

### Тест: `Login screen is shown by default`

**Что проверяет:**
- При запуске приложения по умолчанию отображается экран входа
- На экране присутствует текст "Вход в систему"

**Шаги теста:**
1. Инициализируется приложение через `BookingAppBootstrap.ensureInitialized()`
2. Загружается виджет `BookingApp`
3. Проверяется наличие текста "Вход в систему" на экране

**Ожидаемый результат:** Текст "Вход в систему" найден один раз на экране

## 2. Интеграционные тесты API (backend_flow_test.dart)

### Группа тестов: `Backend flow smoke`

Все тесты используют общий метод `createClient()` для создания API клиента с базовым URL и in-memory провайдером токенов.

### Тест 1: `seller profit matches 10% if sales exist`

**Что проверяет:**
- Прибыль продавца составляет ровно 10% от суммы всех продаж
- Флаг `isPartner` установлен в `false` для роли продавца
- Если продаж нет, прибыль равна 0

**Шаги теста:**
1. Авторизация как продавец (anna@excursion.ru)
2. Получение данных о продажах через `fetchSales()`
3. Получение данных о прибыли через `fetchProfit()`
4. Если есть продажи: проверка что прибыль = продажи × 0.1
5. Проверка что `profit.isPartner == false`
6. Если продаж нет: проверка что прибыль = 0 и breakdown пустой

**Ожидаемый результат:** 
- Прибыль точно равна 10% от продаж (с точностью до 2 знаков)
- Флаг `isPartner` = false

- Админ может изменять цены экскурсий через репозиторий (как в UI)
- Цены обновляются корректно
- Комиссии остаются прежними при обновлении только цен
- После теста цены восстанавливаются

**Шаги теста:**
1. Авторизация как админ
2. Получение списка экскурсий через репозиторий
3. Выбор первой экскурсии
4. Запоминание текущих цен для всех типов
5. Увеличение всех цен на 100
6. Обновление тарифов через `excursionsRepository.updateTariffs()`
7. Проверка что цены изменились
8. Проверка что комиссии остались прежними
9. Восстановление исходных цен

**Ожидаемый результат:**
- Все цены обновлены (увеличены на 100)
- Комиссии остались прежними
- Исходные цены восстановлены
